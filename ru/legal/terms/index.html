Условия использования — Sono AAC Communicator

Последнее обновление: 16 ноября 2026 г.

Матан Любас («мы», «нас», «наш»)

Устанавливая или используя Приложение, вы соглашаетесь соблюдать настоящие Условия. Если вы не согласны с какой-либо частью настоящих Условий, не устанавливайте и не используйте Приложение.

Если Приложение настроено и используется для другого человека (например, ребенка или взрослого, который полагается на поддерживаемую связь), лицо, которое устанавливает и настраивает Приложение («опекун»), несет ответственность за выбор, который он делает в отношении его установки и использования. Лицо может принять настоящие Условия от имени другого лица только в том случае, если оно имеет на это законные полномочия.

2. Кто может использовать приложение

Приложение может использоваться кем угодно. Если Приложение настроено для ребенка или другого лица, которое не может самостоятельно принять юридические условия, родитель, законный опекун или другое уполномоченное по закону лицо должны принять настоящие Условия перед использованием.

Возрастных ограничений на использование коммуникационных функций Приложения нет. Если вы настраиваете Приложение для ребенка, ознакомьтесь с разделом 12 Политики конфиденциальности и получите все разрешения, требуемые действующим законодательством.

3. Описание приложения

Sono — это приложение для общения с помощью изображений и символов, которое позволяет пользователям выражать свои мысли, нажимая на иллюстрированные карточки с символами для построения предложений, которые приложение затем читает вслух с использованием технологии преобразования текста в речь.

Ключевые особенности включают в себя:

  • Настраиваемая доска символов с сотнями иллюстрированных категорий и словарных статей. - Полоса предложений для составления многосимвольных сообщений. - Преобразование текста в речь с использованием автономных моделей голоса (загружаемых по запросу) или встроенной голосовой службы устройства. - Предложения предложений, основанные на детерминированном локальном механизме, основанном на правилах. Некоторые сборки приложения дополнительно предоставляют путь «Принеси свою собственную модель», который позволяет смотрителю импортировать файл языковой модели в формате GGUF и использовать его локально для предложений предложений (см. Раздел 8 и Раздел 11). В приложение не входит ни одна языковая модель.

  • Дополнительная область обучения с уроками. Если сборка настроена с использованием серверной части удаленных уроков, приложение извлекает каталог уроков, содержимое уроков и изображения сцен из этой серверной части через HTTPS и кэширует их локально для автономного воспроизведения; в противном случае доступны только комплексные уроки (см. Раздел 8.2 и Политику конфиденциальности). - Функция резервного копирования, инициируемая смотрителем, которая экспортирует контент, управляемый смотрителем (пользовательские символы, пользовательские фотографии, пользовательские голосовые записи, скрытые элементы, быстрые фразы и конфигурация) в виде архива .sonobkp, а также соответствующая функция импорта (см. Раздел 8.3).

  • Настройки смотрителя для персонализации символов, фотографий, голосовых записей, предпочтительного голоса, макета сетки и поведения доски.

Sono — это приложение для общения, а не приложение для медицинских консультаций или услуг здравоохранения. Ни Приложение, ни его издатель не являются медицинскими работниками и не предоставляют медицинские консультации, диагностику, лечение, клиническую оценку или индивидуальные рекомендации по уходу или терапии. Приложение не предназначено для принятия клинических решений. Проконсультируйтесь с квалифицированным медицинским работником или логопедом по поводу медицинских, терапевтических или индивидуальных потребностей в AAC. Использование приложения не создает отношений между врачом и пациентом. Опекун и пользователь решают, как использовать Приложение для повседневного общения, с учетом ограничений безопасности, указанных в Разделе 11.

  • Загрузите дополнительные модели голоса, чтобы улучшить функциональность речи в автономном режиме.

8. Дополнительные загрузки, импорт, уроки и резервные копии

8.1 Optional model and voice downloads

Приложение может дополнительно загружать или импортировать файлы трех типов по запросу смотрителя:

  • Модели автономного синтеза голоса из проекта Sherpa-ONNX на GitHub (github.com);
  • Голосовые файлы, импортированные смотрителем для функции «Принеси свой собственный голос», полученные по HTTPS с URL-адреса или выбранные смотрителем из памяти устройства;
  • Файлы языковой модели на устройстве в формате GGUF, в которых сборка предоставляет путь «Принесите свою собственную модель» для функции «Умные предложения». Смотритель выбирает источник — обычно репозиторий модели или институциональный URL-адрес — и импортирует файл из хранилища устройства или извлекает его из URL-адреса.

Мы не размещаем эти файлы (кроме случаев, когда это явно указано) и не контролируем их доступность, содержимое, точность, поведение или статус лицензирования. Опекун несет ответственность за проверку того, что любая выбранная им модель или голосовой файл разрешены для использования по назначению в соответствии с его лицензией и применимым законодательством. ###8.2 Дистанционные уроки (если настроено)

Приложение извлекает каталог уроков, файлы JSON отдельных уроков и изображения сцен через HTTPS со своего настроенного медиа-хоста уроков (по умолчанию используется https://ljmatan.github.io/apps/communicator; сборки могут переопределить его во время компиляции с помощью GCM_LESSONS_BASE_URL), когда пользователь открывает область обучения. Загруженное содержимое урока кэшируется локально для воспроизведения в автономном режиме, а ход урока сохраняется локально на устройстве.

Настроенный хост уроков может получать стандартные метаданные HTTPS-запроса, как описано в Политике конфиденциальности. Если настроен отдельный сторонний серверный интерфейс, его условия могут также применяться к предоставляемому им контенту. В сборке по умолчанию для уроков используются страницы GitHub. Если сборка не настроена с использованием серверной части уроков, доступны только объединенные уроки, и удаленное извлечение уроков не происходит.

8.3 Резервное копирование, экспорт и импорт

Приложение включает в себя функцию резервного копирования, инициируемую опекуном, которая объединяет управляемые опекуном записи JSON и пользовательские медиафайлы в архив .sonobkp, а также соответствующую функцию импорта, которая восстанавливает эти записи на устройстве. Содержимое и место хранения архива описаны в разделе 17 Политики конфиденциальности.

Используя функцию резервного копирования, смотритель соглашается с тем, что:
