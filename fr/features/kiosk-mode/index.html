Pour les aidants

Mode kiosque : bloquer la tablette sur le tableau

Gardez l'écran allumé, affichez Sono sur l'écran de verrouillage et épinglez l'application, pour que le tableau soit toujours prêt.

Où la trouver Paramètres de l'aidant > Affichage du tableau > Mode kiosque

Disponible sur Google Play Comment l'utiliser

Sono est une application gratuite de communication alternative et améliorée (CAA) pour Android : la personne touche des images, et l'application parle pour elle.

📌

Un outil de communication n'aide que s'il est prêt. Le mode kiosque garde l'écran allumé tant que le tableau est ouvert. Sur Android, il peut aussi afficher Sono sur l'écran de verrouillage et épingler l'application à l'écran, pour que l'appareil reste sur Sono jusqu'à ce qu'un adulte la désépingle.

Ce que vous pouvez faire

  • Garde l'écran allumé tant que le tableau est ouvert.
  • Affiche Sono sur l'écran de verrouillage.
  • Le bouton Épingler l’app à l’écran maintient l'appareil sur Sono jusqu'à ce que vous désépingliez l'application.
  • Avec Définir comme lanceur par défaut, Sono devient l'écran d'accueil : le bouton d'accueil ramène alors toujours au tableau.

Comment l'utiliser

  1. Ouvrez Paramètres de l'aidant > Affichage du tableau et activez l'option Activer le mode kiosque.
  2. Touchez Épingler l’app à l’écran.
  3. Pour quitter l'épinglage, balayez vers le haut et maintenez, ou maintenez à la fois Retour et Aperçu, selon l'appareil.
  4. Pour faire de Sono l'écran d'accueil, touchez Définir comme lanceur par défaut et choisissez Sono.

Bon à savoir

  • Android oublie l'épinglage après un redémarrage. Ouvrez le même écran et touchez de nouveau Épingler l’app à l’écran.
  • Dans les paramètres de sécurité d'Android, activez la demande du code PIN avant de désépingler, pour que seul un adulte puisse en sortir.
  • Sono est une application de communication, pas un remplacement complet de l'écran d'accueil. Les autres applications restent accessibles aux adultes.

Questions fréquentes

Comment empêcher mon enfant de quitter l'application sur une tablette Android ?

Dans Paramètres de l'aidant > Affichage du tableau, activez l'option Activer le mode kiosque, puis touchez Épingler l’app à l’écran. Par précaution, activez aussi la demande du code PIN avant de désépingler, dans les paramètres de sécurité d'Android.

L'épinglage résiste-t-il à un redémarrage ?

Non. Android oublie l'épinglage après un redémarrage : touchez donc de nouveau Épingler l’app à l’écran.
