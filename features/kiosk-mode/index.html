For caretakers

Kiosk mode: keep the device on the board

Keep the screen awake, show Sono on the lock screen and pin the app, so the board is always ready.

Where to find it Caretaker Settings > Board Display > Kiosk Mode

Get it on Google Play How to use it
📌

A communication device helps only when it's ready. Kiosk mode keeps the screen awake while the board is open. On Android it can also show Sono on the lock screen and pin the app to the screen, so the device stays in Sono until a grown-up unpins it.

What you can do

  • Keeps the screen awake while the board is open.
  • Shows Sono on the lock screen.
  • Pin App to Screen keeps the device in Sono until you unpin it.
  • Set as Default Launcher makes Sono the home screen, so the home button always leads back to the board.

How to use it

  1. Open Caretaker Settings > Board Display and turn on Enable Kiosk Mode.
  2. Tap Pin App to Screen.
  3. To leave pinned mode, swipe up and hold, or hold Back and Recents, depending on the device.
  4. To make Sono the home screen, tap Set as Default Launcher and choose Sono.

Good to know

  • Android forgets the pinning after a restart. Open the same screen and tap Pin App to Screen again.
  • In the Android security settings, turn on asking for a PIN before unpinning, so only a grown-up can leave.
  • Sono is a communication app, not a full replacement for the home screen. Other apps stay within reach for the grown-ups.
