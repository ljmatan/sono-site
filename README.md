# sono.click

Published promo site for the Sono AAC Communicator app, served by GitHub Pages at
https://sono.click/.

This repository holds **built output only**. The source is the Astro project in
`generic_shop_app/plugins/communicator/promo/`; build it with
`PROMO_SITE=https://sono.click PROMO_BASE=/ npm run build` and copy `dist/` here,
keeping `CNAME` and `.nojekyll`.

Lesson media and the copies of the legal pages that the app and the Play listing
link to stay at https://ljmatan.github.io/apps/communicator/.
