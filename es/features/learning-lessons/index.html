Aprender y jugar

Lecciones ilustradas y narradas

Historias ilustradas cortas que convierten las palabras de cada día en pequeñas películas, leídas en voz alta con cada palabra resaltada.

Dónde encontrarla La pestaña Aprender del tablero

Disponible en Google Play Cómo usarla

Sono es una app gratuita de comunicación aumentativa y alternativa (CAA) para Android: la persona toca imágenes y la app habla por ella.

📚

La pestaña Aprender contiene lecciones ilustradas y narradas sobre ocho temas: Animales, Comida, Planetas, Transporte, En casa, Actividades, Naturaleza y Escuela. Cada lección es una breve presentación, con una ilustración para cada escena, un texto leído en voz alta en el que cada palabra se resalta a medida que se dice, música de fondo suave y, a menudo, un breve cuestionario al final.

Qué puedes hacer

  • Narradas en los catorce idiomas de Sono.
  • Descarga una lección una vez y, a partir de entonces, se reproduce sin internet.
  • Las lecciones se descargan de una en una, solo cuando las quieres, para que la app siga ocupando poco.
  • Explora todas las lecciones en la biblioteca de lecciones.

Cómo usarla

  1. Abre la pestaña Aprender y elige un tema.
  2. Toca una lección para descargarla.
  3. Tócala otra vez para reproducirla. Si termina con un cuestionario, toca Hacer el cuestionario.
  4. Para liberar espacio, mantén pulsada una lección descargada para eliminarla.

Conviene saber

  • Para descargar hace falta internet; para reproducir, no.
  • Los temas que todavía no tienen lecciones lo indican.
  • Las lecciones, y también la lista de lecciones, vienen de GitHub Pages, que las aloja para Sono, y al abrir un tema se descarga la lista. La Política de privacidad explica qué contiene esa solicitud.

Preguntas frecuentes

¿Hay cuentos ilustrados que se lean en voz alta para aprender palabras de cada día?

Sí. La pestaña Aprender tiene lecciones ilustradas y narradas sobre ocho temas, de Animales y Comida a Transporte y Escuela, y cada palabra se resalta mientras se lee.

¿Las lecciones funcionan sin conexión?

Sí, una vez descargadas. Toca una lección para descargarla; después se reproduce sin internet.
