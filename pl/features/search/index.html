Talking with symbols

Search for any symbol

Type part of a word and the matching symbols appear, ready to add to the sentence.

Where to find it The Search button on the sentence strip

Pobierz z Google Play How to use it

With more than 800 symbols, scrolling isn't always the fastest way to a word. Search finds a symbol by its name: type a few letters and every matching symbol appears, from every category at once.

What you can do

  • Matches part of a word: “wat” finds water, watermelon and waterfall.
  • Tap a result to add that symbol to the sentence.
  • Finds the person's own symbols from My Symbols too.
  • Hidden symbols stay out of the results.

How to use it

  1. In the Advanced or Menu layout, with the sentence strip empty, tap Search.
  2. Type part of the word.
  3. Tap the symbol you want. It goes onto the sentence strip, and Speak says the sentence.

Good to know

  • Search looks for words in the language Sono is set to, so type the word in that language.
  • Search is as useful to the caretaker as to the person, for example to find a word quickly while modelling.
